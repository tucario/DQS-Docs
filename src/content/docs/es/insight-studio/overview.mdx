## ¿Qué es Insight Studio?

Insight Studio (DIS) es la **capa de visualización y analítica** de Data Quality Sense. Consume los resultados de escaneo y los presenta como paneles interactivos, gráficos y recomendaciones.

## Diseño del espacio de trabajo

Insight Studio utiliza un **diseño de 3 zonas**:

- **Barra lateral** (naranja) — Navegación de objetos/definiciones, filtros y opciones de desglose
- **Escenario** (verde) — Área de contenido principal con puntuaciones, gráficos y tablas de datos
- **Vista general del portfolio** (rojo) — Métricas resumidas, enlaces rápidos y acciones contextuales

## Funcionalidades clave

| Funcionalidad | Descripción |
|---------------|-------------|
| **Navegación multinivel** | Profundice desde Home → Object → Definition → Scan → Field → Dimension |
| **Comparación de puntuaciones** | Compare resultados entre dos escaneos para ver mejora o regresión |
| **Menú de acciones** | Crear Tasks, publicar en Chatter o exportar CSV para registros afectados |
| **Activación de escaneo** | Active manualmente un escaneo desde el panel |
| **Gestión de programación** | Cree y administre programaciones de escaneo |
