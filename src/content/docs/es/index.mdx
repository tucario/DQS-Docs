## ¿Qué es Data Quality Sense?

Data Quality Sense (DQS) es un **paquete gestionado nativo de Salesforce** para monitorear, medir y mejorar la calidad de sus datos CRM. Funciona completamente dentro de su organización Salesforce — sin integraciones externas, sin datos que abandonen su entorno.

La plataforma estándar de Salesforce no proporciona herramientas integradas para medir la calidad de los datos a gran escala. DQS llena este vacío con escaneo automatizado, dimensiones de calidad configurables y análisis enriquecidos.

## Componentes principales

### DQS Builder

Un asistente de múltiples pasos para crear configuraciones de escaneo. Seleccione objetos, elija campos, dimensiones de calidad y establezca umbrales — todo a través de una interfaz guiada.

### Insight Studio

Paneles y análisis de resultados de escaneo. Puntuaciones, tendencias, matrices de salud de campos, comparación de escaneos, exportación CSV y recomendaciones basadas en IA.

### Motor de procesamiento

Escaneo batch automatizado con programación flexible, políticas de retención de datos, gestión de errores y notificaciones mediante eventos de plataforma.

## Dimensiones de calidad

DQS evalúa los datos en **7 dimensiones de calidad**:

| Dimensión | Qué mide |
|-----------|----------|
| **Completeness** | ¿Están los campos completados? |
| **Validity** | ¿Los valores coinciden con los formatos esperados? |
| **Uniqueness** | ¿Hay valores duplicados? |
| **Timeliness** | ¿Los datos están actualizados? |
| **Consistency** | ¿Los campos relacionados son lógicamente consistentes? |
| **PII Detection** | ¿Se manejan correctamente los datos personales? |
| **AI Readiness** | ¿Los datos son aptos para IA/ML? |

Cada dimensión puede configurarse globalmente o por campo, con umbrales y puntuaciones configurables.
