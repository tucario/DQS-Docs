## Cómo funcionan los escaneos

El motor de procesamiento es la **capa de ejecución** de Data Quality Sense. Lee las definiciones de escaneo creadas en el Builder, consulta datos en vivo de Salesforce y produce puntuaciones de calidad visibles en Insight Studio.

![Diálogo de confirmación de Run Scan con tiempo estimado y botón Run Scan](../../../../assets/screenshots/running-scans2.png)

## Activación de un escaneo

Los escaneos pueden activarse de tres maneras:

1. **Manual** — Haga clic en "Run Scan" en Insight Studio
2. **Programado** — Mediante [programación](/es/processing/scheduling/) basada en CRON
3. **Programático** — Mediante API de Apex (para integraciones personalizadas)
