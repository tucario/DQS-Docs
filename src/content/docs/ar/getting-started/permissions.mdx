## مجموعات الصلاحيات

يأتي Data Quality Sense مع مجموعات صلاحيات تتحكم في الوصول إلى أجزاء مختلفة من التطبيق.

### DQS Admin

وصول كامل لجميع الميزات:
- إنشاء وتعديل وحذف تعريفات الفحص
- تكوين القدرات والحدود
- تشغيل وجدولة عمليات الفحص
- عرض جميع النتائج في Insight Studio
- الوصول إلى وحدة تحكم إدارة الأخطاء
- إدارة إعدادات الاحتفاظ بالبيانات

### DQS User

وصول للقراءة فقط للنتائج:
- عرض نتائج الفحص في Insight Studio
- تصدير البيانات إلى CSV
- عرض جداول الفحص

## تعيين مجموعات الصلاحيات

1. انتقل إلى **Setup → Users → Permission Set Assignments** للمستخدم المستهدف
2. انقر على **Edit Assignments**
3. في قائمة **Available Permission Sets**، ابحث عن **DQS Admin** أو **DQS User**
4. انقل مجموعة الصلاحيات المطلوبة إلى **Enabled Permission Sets** باستخدام زر السهم
5. انقر على **Save**

![تعيين مجموعات الصلاحيات في Salesforce Setup يعرض DQS Admin و DQS User في مجموعات الصلاحيات المُفعّلة](../../../../assets/screenshots/permissionsets.png)

<Aside type="caution">
المستخدمون الذين ليس لديهم أي مجموعة صلاحيات DQS معيّنة سيرون بوابة تفعيل عند الوصول إلى التطبيق. ستظهر علامة التبويب Getting Started تلقائيًا لتوجيه المسؤولين خلال عملية الإعداد.
</Aside>

## صلاحيات الكائنات

تمنح مجموعات الصلاحيات تلقائيًا الوصول إلى كائنات DQS المخصصة:

| الكائن | Admin | User |
|--------|-------|------|
| `DQS_Definition__c` | قراءة/إنشاء/تعديل/حذف | قراءة |
| `DQS_Definition_Detail__c` | قراءة/إنشاء/تعديل/حذف | قراءة |
| `DQS_Dimension_Result__c` | قراءة | قراءة |
| `DQS_Field_Result__c` | قراءة | قراءة |
| `DQS_Metric_Result__c` | قراءة | قراءة |
| `DQS_Batch_Schedule__c` | قراءة/إنشاء/تعديل/حذف | قراءة |

## أمان مستوى الحقل

جميع الحقول على كائنات DQS مرئية لكلتا مجموعتي الصلاحيات. نتائج المقاييس والدرجات وحقول التكوين هي للقراءة فقط لمجموعة DQS User.
