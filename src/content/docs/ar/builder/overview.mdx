## ما هو Builder؟

DQS Builder هو **معالج تكوين متعدد الخطوات** يتيح لك تحديد كيفية قياس جودة بياناتك بدقة. يرشدك خلال اختيار الكائنات، وانتقاء الحقول، واختيار أبعاد الجودة، وتعيين الحدود.

## مساحة عمل Builder

يستخدم Builder **تخطيطًا من 3 مناطق**:

- **الشريط الجانبي** — شجرة تنقل تعرض تعريفاتك ومراحل تكوينها (Capabilities، Scope، Filter، Configure، Field Usage، Review)
- **المنصة** — منطقة المحتوى الرئيسية حيث تقوم بتكوين كل خطوة من التعريف
- **لوحة Guidance** — مساعدة سياقية وتوجيه يتكيف مع خطوتك الحالية

## مراحل Builder

1. **Capabilities** — اختر أبعاد الجودة.
2. **Scope** — احفظ الحقول المراد تقييمها.
3. **Filter** — اضبط مرشحات السجلات أو أكد عدم الحاجة إلى مرشح.
4. **Configure** — اضبط القدرات وأكد إعداداتها باستخدام **Confirm Configuration**.
5. **Field Usage (optional)** — فعّل تقارير استخدام البيانات الوصفية اختياريًا واحفظ تحديد الحقول.
6. **Review** — راجع التعريف وأكمله.

يجب إنهاء التكوين المطلوب قبل إكمال التعريف. Field Usage اختياري ومعطل افتراضيًا ولا يؤثر على فحوص الجودة. بعد Configure، يفتح **Continue** خطوة Field Usage. احفظ التغييرات قبل المتابعة أو استخدام **Mark as Complete**، المتاح في Field Usage وReview.
