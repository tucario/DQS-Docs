## كيف يعمل التقييم

تنتج كل قدرة **درجة من 0 إلى 100** لكل حقل يتم فحصه:

- **100** — جودة مثالية لهذا البُعد
- **75–99** — جيدة، مع مشكلات طفيفة
- **50–74** — جودة متوسطة، يُوصى بالانتباه
- **0–49** — جودة ضعيفة، يلزم اتخاذ إجراء
- **0** — لا توجد بيانات للقياس (مثل جميع الحقول فارغة)

يتم تجميع الدرجات:
1. **درجة الحقل** — نتيجة الحقل الفردي لكل قدرة
2. **درجة البُعد** — المتوسط عبر جميع الحقول لقدرة واحدة
3. **درجة التعريف** — المتوسط المرجح عبر جميع الأبعاد
