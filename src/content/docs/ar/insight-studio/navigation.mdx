## عمق التنقل

يوفر Insight Studio تسلسلًا هرميًا من **6 مستويات للتنقل التفصيلي**:

```
Home → Object → Definition → Scan → Field → Dimension
```

### المستوى 1: الرئيسية

العرض الأعلى مستوى يظهر جميع الكائنات التي تم فحصها مع أحدث درجات جودتها. استخدمه لتحديد الكائنات التي تحتاج إلى اهتمام.

![الرئيسية DQS — نظرة عامة مع عدد التعريفات وعمليات الفحص والجداول النشطة وجدول النشاط الأخير](../../../../assets/screenshots/dqs-home.png)

تتضمن صفحة Home أيضًا لوحة **Configuration** حيث يمكن للمسؤولين تعديل المعلمات الافتراضية مثل Scan Result Retention Days وPurge Batch Size وPurge CRON Expression وError Log Retention Days مباشرة من الواجهة.

![لوحة Configuration في DQS Home — معلمات افتراضية قابلة للتعديل لإعدادات الاحتفاظ والحذف](../../../../assets/screenshots/configuration-editable.png)

### المستوى 2: الكائن

يعرض جميع التعريفات لكائن محدد مع درجة الجودة الشاملة وتاريخ آخر فحص والحالة وبطاقات التعريف. قارن تكوينات الفحص المختلفة ونتائجها جنبًا إلى جنب.

![عرض الكائن لـ Case — درجة إجمالية 64.7%، تعريفان مع درجات فردية وعدد عمليات الفحص](../../../../assets/screenshots/object-with-definitions.png)

### المستوى 3: التعريف

لوحة المعلومات الرئيسية لتعريف واحد. تحتوي على أربع علامات تبويب:

- **نظرة عامة** — درجة الجودة الشاملة، أشرطة درجات الأبعاد، مخطط اتجاه الدرجات، ولوحة درجات السجلات
- **الحقول** — مصفوفة صحة الحقول مع درجات كل حقل عبر الأبعاد
- **عمليات الفحص** — سجل كامل لعمليات الفحص مع نتائج كل تشغيل
- **التصدير** — تنزيل تفاصيل المخالفات كـ CSV لكل بُعد وحقل، أو اتخاذ إجراء عبر إنشاء مهام ونشر Chatter

![لوحة معلومات التعريف — درجة إجمالية 85.8%، تفصيل الأبعاد، مخطط اتجاه الدرجات، ودرجات السجلات](../../../../assets/screenshots/object-with-latest-scans.png)

تعرض علامة التبويب **الحقول** درجة كل حقل لكل بُعد في مصفوفة مُرمّزة بالألوان — الأحمر للضعيف والأخضر للجيد. استخدمها لاكتشاف الحقول الأضعف بسرعة.

![علامة تبويب الحقول — مصفوفة صحة الحقول مع الدرجات لكل بُعد، مُرمّزة بالألوان حسب التصنيف](../../../../assets/screenshots/object-fields-section.png)

تسرد علامة التبويب **التصدير** عمليات التصدير المتاحة لكل بُعد وحقل، مع أزرار التنزيل وسجل التصدير.

![علامة تبويب التصدير — سجل التصدير وأزرار التصدير لكل حقل لكل بُعد](../../../../assets/screenshots/object-exports-tab.png)

من علامة التبويب نظرة عامة، انقر على **Compare** في مخطط اتجاه الدرجات لمقارنة فحصين جنبًا إلى جنب — شاهد فروقات مستوى البُعد ومستوى الحقل بين فحص أساسي وفحص مقارنة.

![نافذة مقارنة النتائج — الأساسي مقابل المقارنة مع تغييرات الأبعاد وأهم فروقات الحقول](../../../../assets/screenshots/object-compare-results.png)

### المستوى 4: الفحص

نتائج تفصيلية لتنفيذ فحص محدد. تعرض علامة التبويب **عمليات الفحص** سجل الفحص الكامل مع مؤشرات الحالة والدرجات وتفصيلات الأبعاد لكل تشغيل.

![علامة تبويب عمليات الفحص تعرض سجل الفحص مع التواريخ والدرجات والحالة ونتائج كل بُعد](../../../../assets/screenshots/object-scans-tab.png)

### المستوى 5: الحقل

نتائج حقل واحد عبر جميع الأبعاد. مفيد لفهم سبب حصول حقل معين على درجة ضعيفة.

### المستوى 6: البُعد

المستوى الأعمق — نتائج المقاييس الفردية لحقل واحد في بُعد واحد. يعرض بيانات التقييم الخام.

## لوحة الشريط الجانبي

يعرض الشريط الجانبي الأيمن السياق والإجراءات للتعريف الحالي:

- **الرأس** — اسم التعريف، الدرجة الشاملة مع التصنيف، عدد عمليات الفحص، وزر التحديث
- **تشغيل الفحص** — تشغيل فحص يدويًا، مع عرض تاريخ آخر فحص أدناه
- **التحليل** — قائمة منسدلة **إجراءات** مع **تقرير التصدير**، **إنشاء مهام**، و **نشر Chatter** ([التفاصيل](/ar/insight-studio/actions/))
- **التكوين** — **إدارة الجدول** مع عد تنازلي للتشغيل المجدول التالي (مثل "التالي في 8 ساعات و28 دقيقة")
- **التنقل** — **فتح في Salesforce** (رابط خارجي لسجل التعريف) و **عرض السجلات** (تصفح السجلات التي تم فحصها)
- **الإصلاح السريع** — يُبرز الحقل الأضعف أداءً مع درجته (مثل "Description بنسبة 9.6% — أضعف حقل") ورابط **تحقيق** مباشر للتنقل إليه

![لوحة الشريط الجانبي مع أقسام تشغيل الفحص والتحليل والتكوين والتنقل والإصلاح السريع](../../../../assets/screenshots/sidebar-panel.png)

## تنقل المسار التفصيلي

يظهر مسار تفصيلي في أعلى منطقة المنصة يعرض موقعك الحالي في التسلسل الهرمي. انقر على أي جزء من المسار للعودة إلى ذلك المستوى.

![مسار التنقل التفصيلي: Home → Case → Case SLA Compliance Check → DQR-0007 → Case Number](../../../../assets/screenshots/insight-studio-breadcumbs.png)
