## ما هو Insight Studio؟

Insight Studio (DIS) هو **طبقة التصور والتحليلات** في Data Quality Sense. يستهلك نتائج الفحص ويعرضها كلوحات معلومات تفاعلية ورسوم بيانية وتوصيات.

## تخطيط مساحة العمل

يستخدم Insight Studio **تخطيطًا من 3 مناطق**:

- **الشريط الجانبي** (برتقالي) — تنقل الكائنات/التعريفات، الفلاتر، وخيارات التفصيل
- **المنصة** (أخضر) — منطقة المحتوى الرئيسية مع الدرجات والرسوم البيانية وجداول البيانات
- **نظرة عامة على المحفظة** (أحمر) — مقاييس ملخصة، روابط سريعة وإجراءات سياقية

## الميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| **تنقل متعدد المستويات** | التنقل من الرئيسية → الكائن → التعريف → الفحص → الحقل → البُعد |
| **مقارنة الدرجات** | مقارنة النتائج بين فحصين لمعرفة التحسن أو التراجع |
| **قائمة الإجراءات** | إنشاء مهام، نشر Chatter، أو تصدير CSV للسجلات المتأثرة |
| **تشغيل الفحص** | تشغيل فحص يدويًا من لوحة المعلومات |
| **إدارة الجداول** | إنشاء وإدارة جداول الفحص |
