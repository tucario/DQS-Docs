## عرض الدرجات

يعرض كل مستوى في Insight Studio درجات الجودة مع مؤشرات بصرية:

### تصنيفات الدرجات

| نطاق الدرجة | التصنيف | اللون |
|-------------|---------|-------|
| 90–100 | ممتاز | أخضر |
| 75–89 | جيد | أخضر فاتح |
| 50–74 | مقبول | أصفر/برتقالي |
| 25–49 | ضعيف | برتقالي |
| 0–24 | حرج | أحمر |

![نتيجة الحقل — معدل الاكتمال 100%، تحليل معدل التعبئة، أشرطة استخدام الحقل، وتفاصيل التكوين](../../../../assets/screenshots/insight-studio-field-result.png)

### بطاقات الدرجات

تعرض لوحة معلومات التعريف **بطاقات الأبعاد** — واحدة لكل قدرة مُفعّلة — مع:
- درجة رقمية (0–100)
- مؤشر تصنيف (مُرمّز بالألوان)
- سهم تغيير (↑ تحسن، ↓ تراجع، → مستقر)
- رسم بياني مصغر يعرض الاتجاه الأخير

## تحليل الاتجاهات

### الرسوم البيانية المصغرة

رسوم بيانية صغيرة مضمّنة بجانب كل درجة تعرض نتائج عمليات الفحص الأخيرة. مفيدة لاكتشاف الاتجاهات دون الانتقال إلى عروض تفصيلية.

### مخطط اتجاه الدرجات

مخطط اتجاه أكبر متاح على مستوى التعريف يعرض:
- الدرجة بمرور الوقت لكل بُعد
- خط اتجاه الدرجة الشاملة
- تواريخ الفحص على المحور الأفقي

### مقارنة الفحص

![نافذة مقارنة النتائج — فحص أساسي مقابل فحص مقارنة مع فروقات الأبعاد ومستوى الحقل](../../../../assets/screenshots/insight-studio-compare.png)

قارن فحصين محددين لمعرفة الفروقات التفصيلية:
- **فروقات الأبعاد** — أي القدرات تحسنت أو تراجعت
- **فروقات الحقول** — أي الحقول تغيرت وبكم
- اختر أي فحصين من سجل الفحص

## العروض ذات الحالتين

تتكيف بعض المكونات بناءً على توفر البيانات:
- **لا توجد عمليات فحص بعد** — يعرض رسالة تحث على تشغيل أول فحص
- **النتائج متاحة** — يعرض لوحة المعلومات الكاملة مع الدرجات والرسوم البيانية

## ملخص مؤشرات الأداء الرئيسية

يعرض أعلى عرض التعريف مؤشرات الأداء الرئيسية:
- **الدرجة الشاملة** — المتوسط المرجح عبر جميع الأبعاد
- **الحقول التي تم فحصها** — إجمالي الحقول المُضمّنة
- **السجلات التي تم تقييمها** — إجمالي السجلات في النطاق
- **آخر فحص** — الطابع الزمني لأحدث فحص
