## الكائنات المخصصة

يستخدم DQS مجموعة من الكائنات المخصصة لتخزين التعريفات والنتائج وبيانات الجدولة. تستخدم جميع الكائنات بادئة مساحة الأسماء `dqssens`.

### كائنات التعريف

| الكائن | الغرض | الحقول الرئيسية |
|--------|-------|----------------|
| `DQS_Definition__c` | تكوين الفحص | الاسم، اسم API للكائن، الحالة، الوصف |
| `DQS_Definition_Detail__c` | تكوين مستوى الحقل | التعريف (lookup)، اسم API للحقل، التخصيصات |

### كائنات النتائج

| الكائن | الغرض | العلاقة |
|--------|-------|---------|
| `DQS_Dimension_Result__c` | نتيجة فحص لكل بُعد | التعريف (lookup) |
| `DQS_Field_Result__c` | نتيجة لكل حقل ضمن بُعد | نتيجة البُعد (master-detail) |
| `DQS_Metric_Result__c` | مقياس تفصيلي لكل حقل | نتيجة الحقل (master-detail) |

### كائنات الجدولة

| الكائن | الغرض |
|--------|-------|
| `DQS_Batch_Schedule__c` | تخزين تكوين الجدول لكل تعريف |

## علاقات الكائنات

```
DQS_Definition__c
  ├── DQS_Definition_Detail__c (1:N)
  ├── DQS_Batch_Schedule__c (1:1)
  └── DQS_Dimension_Result__c (1:N per scan)
       └── DQS_Field_Result__c (1:N, master-detail)
            └── DQS_Metric_Result__c (1:N, master-detail)
```

## Custom Metadata Types

تقود CMTs تكوين القدرات ومنطق التقييم الخاص بها. يتم التحكم فيها من الحزمة ولا يمكن للمشتركين تعديلها (إلا حيث يُذكر ذلك).

| CMT | الغرض | السجلات |
|-----|-------|---------|
| `DQS_Capability__mdt` | تحديد أبعاد الجودة المتاحة | 7 (واحد لكل قدرة) |
| `DQS_Dimension__mdt` | تكوين عرض البُعد | 7 |
| `DQS_Metric__mdt` | تعريفات المقاييس لكل قدرة | متعددة لكل بُعد |
| `DQS_Input_Configuration__mdt` | إعدادات مُكوّن الإدخال | حقول تكوين لكل قدرة |
| `DQS_Configuration__mdt` | إعدادات التطبيق العامة | الاحتفاظ، علامات الميزات |

## أحداث المنصة

| الحدث | الغرض |
|-------|-------|
| `Calculation_Complete__e` | يُطلق عند انتهاء معالجة الفحص |
| `DQS_Processing_Error__e` | يُطلق عند حدوث خطأ أثناء المعالجة الدُفعية |

## معلمات الميزات

| المعلمة | الغرض |
|---------|-------|
| `DQS_AppEnabled` | يتحكم في بوابة التفعيل — ما إذا كان التطبيق مُرخّصًا ونشطًا |
