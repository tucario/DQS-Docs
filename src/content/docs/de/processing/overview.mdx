## Wie Scans funktionieren

Die Verarbeitungs-Engine ist die **Ausführungsschicht** von Data Quality Sense. Sie liest im Builder erstellte Scan-Definitionen, fragt Live-Salesforce-Daten ab und erzeugt Qualitätsbewertungen, die in Insight Studio sichtbar sind.

![Scan-Bestätigungsdialog mit geschätzter Zeit und Run Scan-Schaltfläche](../../../../assets/screenshots/running-scans2.png)

## Scan auslösen

Scans können auf drei Arten ausgelöst werden:

1. **Manuell** — Klicken Sie auf „Run Scan" in Insight Studio
2. **Geplant** — Über CRON-basierte [Zeitplanung](/de/processing/scheduling/)
3. **Programmatisch** — Über Apex API (für benutzerdefinierte Integrationen)
