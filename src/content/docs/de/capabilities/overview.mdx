## Die 6 Dimensionen der Datenqualität

Data Quality Sense bewertet Ihre Daten anhand von **6 unterschiedlichen Qualitätsdimensionen** (Capabilities). Jede Dimension konzentriert sich auf einen anderen Aspekt der Datenqualität und erzeugt unabhängige Bewertungen, die zu einer Gesamtqualitätsbewertung zusammengefasst werden.

## Wie die Bewertung funktioniert

Jede Capability erzeugt eine **Bewertung von 0 bis 100** für jedes gescannte Feld:

- **100** — Perfekte Qualität für diese Dimension
- **75–99** — Gut, mit geringfügigen Problemen
- **50–74** — Moderate Qualität, Aufmerksamkeit empfohlen
- **0–49** — Schlechte Qualität, Handlung erforderlich
- **0** — Keine Daten zu messen (z. B. alle Felder leer)

Bewertungen werden aggregiert:
1. **Feldbewertung** — Einzelnes Feldergebnis pro Capability
2. **Dimensionsbewertung** — Durchschnitt über alle Felder für eine Capability
3. **Definitionsbewertung** — Gewichteter Durchschnitt über alle Dimensionen

## Capability-Anwendbarkeit

Nicht alle Capabilities gelten für alle Feldtypen. DQS behandelt nicht anwendbare Kombinationen automatisch:

| Feldtyp | Completeness | Validity | Uniqueness | Timeliness | Consistency | PII Detection |
|---------|:---:|:---:|:---:|:---:|:---:|:---:|
| Text | ✓ | ✓ | ✓ | — | ✓ | ✓ |
| Number | ✓ | ✓ | ✓ | — | ✓ | — |
| Date | ✓ | ✓ | — | ✓ | ✓ | — |
| Picklist | ✓ | ✓ | — | — | ✓ | — |
| Boolean | ✓ | — | — | — | ✓ | — |
| Email | ✓ | ✓ | ✓ | — | — | ✓ |
| Phone | ✓ | ✓ | ✓ | — | — | ✓ |
