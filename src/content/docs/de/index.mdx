## Was ist Data Quality Sense?

Data Quality Sense (DQS) ist ein **Salesforce-natives Managed Package** zur Überwachung, Messung und Verbesserung der Qualität Ihrer CRM-Daten. Es läuft vollständig innerhalb Ihrer Salesforce-Organisation — keine externen Integrationen, keine Daten verlassen Ihre Umgebung.

Die Standard-Salesforce-Plattform bietet keine integrierten Tools zur Messung der Datenqualität in großem Maßstab. DQS füllt diese Lücke mit automatisiertem Scanning, konfigurierbaren Qualitätsdimensionen und umfangreichen Analysen.

## Kernkomponenten

### DQS Builder

Ein mehrstufiger Assistent zur Erstellung von Scan-Konfigurationen. Wählen Sie Objekte aus, wählen Sie Felder, wählen Sie Qualitätsdimensionen und legen Sie Schwellenwerte fest — alles über eine geführte Benutzeroberfläche.

### Insight Studio

Dashboards und Analysen für Scan-Ergebnisse. Bewertungen, Trends, Feldgesundheitsmatrizen, Scan-Vergleich, CSV-Export und KI-gestützte Empfehlungen.

### Verarbeitungs-Engine

Automatisiertes Batch-Scanning mit flexibler Planung, Datenaufbewahrungsrichtlinien, Fehlermanagement und Platform-Event-Benachrichtigungen.

## Qualitätsdimensionen

DQS bewertet Daten über **7 Qualitätsdimensionen**:

| Dimension | Was wird gemessen |
|-----------|-----------------|
| **Completeness** | Sind die Felder ausgefüllt? |
| **Validity** | Entsprechen die Werte den erwarteten Formaten? |
| **Uniqueness** | Gibt es doppelte Werte? |
| **Timeliness** | Sind die Daten aktuell? |
| **Consistency** | Sind verbundene Felder logisch konsistent? |
| **PII Detection** | Werden persönliche Daten korrekt behandelt? |
| **AI Readiness** | Sind die Daten für KI/ML geeignet? |

Jede Dimension kann global oder pro Feld konfiguriert werden, mit konfigurierbaren Schwellenwerten und Bewertungen.
