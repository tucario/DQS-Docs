## What is the Builder?

The DQS Builder is a **multi-step configuration wizard** that lets you define exactly how your data quality should be measured. It guides you through selecting objects, picking fields, choosing quality dimensions, and setting thresholds.

## Builder Workspace

The Builder uses a **3-zone layout**:

- **Sidebar** — Navigation tree showing your definitions and their configuration stages (Capabilities, Scope, Filter, Configure, Field Usage, Review)
- **Stage** — Main content area where you configure each step of the definition
- **Guidance Panel** — Contextual help and guidance that adapts to your current step

## Key Concepts

<CardGrid>
	<Card title="Definition" icon="document">

	</Card>
	<Card title="Capability" icon="approve-check-circle">
		A quality dimension like Completeness or Validity. Each capability can be configured globally or overridden per field.
	</Card>
	<Card title="Definition Detail" icon="list-format">
		A record linking a specific field to a definition, storing per-field configuration overrides for each capability.
	</Card>
	<Card title="Lifecycle" icon="setting">
		Definitions progress through stages: Draft → Ready → Active → Obsolete. Only Active definitions can be scanned.
	</Card>
</CardGrid>

## Builder Stages

1. **Capabilities** — Select quality dimensions.
2. **Scope** — Save the fields to evaluate.
3. **Filter** — Set record filters or confirm that no filter is needed.
4. **Configure** — Configure capabilities and use **Confirm Configuration** to confirm their settings.
5. **Field Usage (optional)** — Optionally enable metadata usage reports and save the field selection.
6. **Review** — Review the definition and complete it.

Required configuration must be complete before finishing the definition. Field Usage is optional and disabled by default; it does not affect quality scans. After Configure, **Continue** opens Field Usage. Save any Field Usage edits before continuing or using **Mark as Complete**, which is available in Field Usage and Review.
