## Field Picker

The field picker is the second stage of the Builder wizard. It displays all available fields on your selected object in a paginated table.

## Features

### Search and Filter

- **Search** — Filter fields by label or API name
- **Field Type Filter** — Show only specific field types (Text, Number, Picklist, etc.)
- **Sortable Columns** — Sort by field label, API name, or field type

### Field Information

For each field, the picker displays:

| Column | Description |
|--------|-------------|
| **Label** | The field's display name |
| **API Name** | The developer name (e.g., `BillingCity`) |
| **Type** | Field data type (Text, Number, Date, Picklist, etc.) |
| **Required** | Whether the field is required on the layout |

### Bulk Selection

Use the checkbox in the header row to select or deselect all visible fields. Selections persist across pages — you can select fields on page 1, navigate to page 2, and your selections are preserved.

## Field Considerations

<Aside type="tip">
Not all field types are applicable to all capabilities. For example, Uniqueness may not be meaningful for Boolean fields. DQS automatically handles non-applicable combinations.
</Aside>

### Recommended Fields

For a comprehensive scan, include:
- **Key identifier fields** — Name, Email, Phone
- **Address fields** — for Completeness and Validity
- **Date fields** — for Timeliness
- **Picklist fields** — for Validity and Consistency
- **Free text fields** — for Completeness and PII Detection

### Fields to Avoid

- System-generated fields (Id, CreatedDate, LastModifiedDate) — these are always populated
- Formula fields — their values are computed, not entered by users
- Encrypted fields — may not be readable by the scan engine

## Scope View

After selecting fields, the **Scope View** shows a summary of your selections grouped by field type, making it easy to verify your configuration before proceeding to capability selection.
