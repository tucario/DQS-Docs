## Czym jest Insight Studio?

Insight Studio (DIS) to **warstwa wizualizacji i analiz** Data Quality Sense. Przetwarza wyniki skanów i prezentuje je jako interaktywne pulpity, wykresy i rekomendacje.

## Układ przestrzeni roboczej

Insight Studio wykorzystuje **układ 3-strefowy**:

- **Sidebar** (pomarańczowy) — Nawigacja po obiektach/definicjach, filtry i opcje podziału
- **Stage** (zielony) — Główny obszar z wynikami, wykresami i tabelami danych
- **Przegląd portfolio** (czerwony) — Podsumowanie metryk, szybkie linki i kontekstowe akcje

## Kluczowe funkcje

| Funkcja | Opis |
|---------|------|
| **Nawigacja wielopoziomowa** | Przechodzenie od Home → Object → Definition → Scan → Field → Dimension |
| **Porównanie wyników** | Porównanie wyników między dwoma skanami, aby zobaczyć poprawę lub regresję |
| **Menu akcji** | Tworzenie zadań, publikowanie w Chatter lub eksport CSV dla rekordów z problemami |
| **Wyzwalanie skanu** | Ręczne wyzwolenie skanu z pulpitu |
| **Zarządzanie harmonogramami** | Tworzenie i zarządzanie harmonogramami skanów |
