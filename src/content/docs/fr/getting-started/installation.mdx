## Prérequis

- Organisation Salesforce (édition Enterprise, Unlimited ou Developer)
- Profil System Administrator ou permissions équivalentes
- Lightning Experience activé

## Installer le package

1. **Obtenir le lien d'installation**

   Utilisez le lien de version ci-dessus. Vérifiez le nom du package et sa version dans l’installateur Salesforce.

2. **Choisir le périmètre d'installation**

   Sélectionnez qui doit avoir accès :
   - **Install for Admins Only** — recommandé pour la configuration initiale
   - **Install for All Users** — si tous les utilisateurs ont besoin d'un accès immédiat
   - **Install for Specific Profiles** — pour un contrôle granulaire

   ![Installer Data Quality Sense — choisir le périmètre d'installation](../../../../assets/screenshots/installation-appexchange.png)

3. **Vérifier les accès du package**

   Field Usage lit les métadonnées via les API Salesforce dans votre org. Le code source n’est pas envoyé à un service d’analyse externe.

4. **Attendre la fin de l'installation**

   L'installateur affiche la progression. Pour les organisations de grande taille, l'installation peut prendre quelques minutes — vous recevrez un e-mail une fois l'opération terminée.

   ![Installation en cours](../../../../assets/screenshots/installation-in-progress.png)

   ![Installation plus longue que prévu — notification par e-mail à suivre](../../../../assets/screenshots/installation-taking-longer.png)

5. **Vérifier l'installation**

   Accédez à **Setup → Installed Packages** et confirmez que `Data Quality Sense` apparaît avec le namespace `dataqualitysens`.

   ![Installed Packages dans Salesforce Setup affichant le package Data Quality Sense](../../../../assets/screenshots/installed-packages.png)

<Aside type="tip">
Après l'installation, consultez la page [Permissions](/fr/getting-started/permissions/) pour configurer l'accès des utilisateurs.
</Aside>

## Activer l'application

Après l'installation, Data Quality Sense n'est **pas encore actif**. Lorsque vous ouvrez l'application pour la première fois, vous verrez un écran de verrouillage indiquant que l'activation est requise.

![Data Quality Sense n'est pas activé — écran de verrouillage avec le bouton Contact Us to Activate](../../../../assets/screenshots/installation-not-activated.png)

Cliquez sur **Contact Us to Activate** pour ouvrir un e-mail pré-rempli avec votre Org ID et les détails. Vous pouvez également nous contacter directement à [hello@tucario.com](mailto:hello@tucario.com).

![E-mail de demande d'activation pré-rempli avec l'Org ID](../../../../assets/screenshots/send-email-to-activate.png)

Nous activerons l'application à distance — aucune étape d'installation supplémentaire n'est nécessaire de votre côté. Une fois activé, l'écran de verrouillage disparaît et l'application est prête à l'emploi avec **20 scans** inclus.

<Aside type="note">
L'activation est liée à votre organisation Salesforce. Si vous installez le package sur une nouvelle organisation (par exemple, un sandbox), il doit être activé séparément.
</Aside>

## Post-installation

Le package installe tous les composants nécessaires — objets personnalisés, composants Lightning et jeux d'autorisations. Aucune configuration supplémentaire de ces composants n'est nécessaire.

## Mise à jour du package

Pour une mise à niveau, utilisez le lien d’installation de la version cible. Un lien contenant un identifiant de version sélectionne toujours cette version, pas automatiquement les versions futures. Vérifiez les versions installée et cible dans Salesforce, puis choisissez **Upgrade** si cette option est proposée.

![Mise à niveau de Data Quality Sense — Salesforce détecte le package existant et propose un chemin de mise à niveau](../../../../assets/screenshots/upgrade-package.png)

Vos définitions de scan, résultats et configurations sont préservés lors des mises à jour — aucune donnée n'est perdue.
