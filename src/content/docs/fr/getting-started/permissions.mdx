## Attribuer un Permission Set Group

Attribuez un groupe fourni par le package pour chaque rôle :

| Rôle | Groupe dans Setup | Nom API | Permission Sets inclus |
| --- | --- | --- | --- |
| Utilisateur | **DQS User Access** | `DQS_User_Group` | `dqs_user` |
| Administrateur | **DQS Administrator Access** | `DQS_Admin_Group` | `dqs_user` + `dqs_admin` |

Dans **Setup → Permission Set Groups**, ouvrez le groupe, choisissez **Manage Assignments → Add Assignments**, sélectionnez les utilisateurs et terminez l’attribution. Le groupe administrateur inclut l’accès de base ; inutile d’attribuer les deux groupes.

Les attributions directes existantes restent valides et ne sont pas migrées automatiquement. En attribution directe, les administrateurs ont besoin de `dqs_user` et `dqs_admin` ; `dqs_admin` seul ne constitue pas le rôle complet.

## Capacités des rôles

**DQS User Access n’est pas un accès en lecture seule.** Les utilisateurs peuvent créer et modifier des définitions Draft, configurer les capacités et les paramètres par champ, importer des champs depuis une mise en page, lancer des scans et consulter les résultats. Le Permission Set de base accorde aussi la création, la lecture, la modification et la suppression sur les principaux objets DQS de définition, résultat, planification et journal d’erreurs. Les règles de l’application ajoutent des restrictions.

**DQS Administrator Access** ajoute les opérations d’administration, dont la suppression des définitions Draft et la configuration, la génération, l’historique et l’export PDF de Field Usage. Même un administrateur DQS ne peut pas supprimer une définition active.

## Accès aux données et activation

Les droits sur les objets et les champs s’appliquent toujours aux données Salesforce analysées. L’accès DQS ne garantit pas l’accès à tous les objets sources, champs ou métadonnées. Les paramètres Field Usage et les rapports enregistrés nécessitent un accès administrateur, absent du rôle de base.

Attribuer un groupe n’active pas le package. Effectuez séparément l’[activation de l’application](/fr/getting-started/installation/) après l’installation.
