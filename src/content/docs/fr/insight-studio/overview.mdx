## Qu'est-ce qu'Insight Studio ?

Insight Studio (DIS) est la **couche de visualisation et d'analyse** de Data Quality Sense. Il consomme les résultats des scans et les présente sous forme de tableaux de bord interactifs, de graphiques et de recommandations.

## Disposition de l'espace de travail

Insight Studio utilise une **disposition en 3 zones** :

- **Barre latérale** (orange) — Navigation par objet/définition, filtres et options de répartition
- **Zone principale** (vert) — Zone de contenu principale avec scores, graphiques et tableaux de données
- **Vue d'ensemble du portfolio** (rouge) — Métriques résumées, liens rapides et actions contextuelles

## Fonctionnalités clés

| Fonctionnalité | Description |
|----------------|-------------|
| **Navigation multi-niveaux** | Naviguez de Home → Object → Definition → Scan → Field → Dimension |
| **Comparaison de scores** | Comparez les résultats entre deux scans pour voir les améliorations ou régressions |
| **Menu Actions** | Créer des Tasks, publier des messages Chatter ou exporter en CSV pour les enregistrements impactés |
| **Déclenchement de scan** | Déclenchez manuellement un scan depuis le tableau de bord |
| **Gestion des planifications** | Créez et gérez les planifications de scans |
