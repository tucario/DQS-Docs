## Qu'est-ce que le Builder ?

Le DQS Builder est un **assistant de configuration multi-étapes** qui vous permet de définir précisément comment la qualité de vos données doit être mesurée. Il vous guide dans la sélection des objets, le choix des champs, la sélection des dimensions de qualité et la définition des seuils.

## Espace de travail du Builder

Le Builder utilise une **disposition en 3 zones** :

- **Barre latérale** — Arborescence de navigation montrant vos définitions et leurs étapes de configuration (Capabilities, Scope, Filter, Configure, Field Usage, Review)
- **Zone principale** — Zone de contenu principale où vous configurez chaque étape de la définition
- **Panneau Guidance** — Aide contextuelle et conseils qui s'adaptent à votre étape actuelle

## Concepts clés

<CardGrid>
	<Card title="Définition" icon="document">
		Une configuration de scan qui spécifie quel objet, quels champs et quelles capacités de qualité évaluer. Chaque définition produit un ensemble de résultats lorsqu'elle est scannée.
	</Card>
	<Card title="Capacité" icon="approve-check-circle">
		Une dimension de qualité comme Completeness ou Validity. Chaque capacité peut être configurée globalement ou surchargée par champ.
	</Card>
	<Card title="Détail de définition" icon="list-format">
		Un enregistrement liant un champ spécifique à une définition, stockant les surcharges de configuration par champ pour chaque capacité.
	</Card>
	<Card title="Cycle de vie" icon="setting">
		Les définitions progressent à travers des étapes : Draft → Ready → Active → Obsolete. Seules les définitions actives peuvent être scannées.
	</Card>
</CardGrid>

## Étapes du Builder

1. **Capabilities** — Sélectionnez les dimensions de qualité.
2. **Scope** — Enregistrez les champs à évaluer.
3. **Filter** — Définissez les filtres de données ou confirmez qu’aucun filtre n’est nécessaire.
4. **Configure** — Configurez les capacités et confirmez leurs paramètres avec **Confirm Configuration**.
5. **Field Usage (optional)** — Activez éventuellement les rapports d’utilisation des métadonnées et enregistrez la sélection des champs.
6. **Review** — Vérifiez et terminez la définition.

La configuration obligatoire doit être terminée avant de finaliser la définition. Field Usage est facultatif et désactivé par défaut ; il n’affecte pas les scans de qualité. Après Configure, **Continue** ouvre Field Usage. Enregistrez les modifications avant de continuer ou d’utiliser **Mark as Complete**, disponible dans Field Usage et Review.
