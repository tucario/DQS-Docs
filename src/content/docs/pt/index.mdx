## O que é Data Quality Sense?

Data Quality Sense (DQS) é um **pacote gerenciado nativo Salesforce** para monitorar, medir e melhorar a qualidade dos seus dados CRM. Funciona inteiramente dentro da sua organização Salesforce — sem integrações externas, sem dados saindo do seu ambiente.

A plataforma Salesforce padrão não fornece ferramentas integradas para medir a qualidade dos dados em escala. O DQS preenche essa lacuna com varredura automatizada, dimensões de qualidade configuráveis e análises ricas.

## Componentes principais

### DQS Builder

Um assistente de múltiplas etapas para criar configurações de varredura. Selecione objetos, escolha campos, dimensões de qualidade e defina limites — tudo através de uma interface guiada.

### Insight Studio

Dashboards e análises de resultados de varredura. Pontuações, tendências, matrizes de saúde de campos, comparação de varreduras, exportação CSV e recomendações baseadas em IA.

### Motor de processamento

Varredura batch automatizada com agendamento flexível, políticas de retenção de dados, gestão de erros e notificações por eventos de plataforma.

## Dimensões de qualidade

O DQS avalia os dados em **7 dimensões de qualidade**:

| Dimensão | O que mede |
|----------|-----------|
| **Completeness** | Os campos estão preenchidos? |
| **Validity** | Os valores correspondem aos formatos esperados? |
| **Uniqueness** | Existem valores duplicados? |
| **Timeliness** | Os dados estão atualizados? |
| **Consistency** | Os campos relacionados são logicamente consistentes? |
| **PII Detection** | Os dados pessoais são tratados corretamente? |
| **AI Readiness** | Os dados são adequados para IA/ML? |

Cada dimensão pode ser configurada globalmente ou por campo, com limites e pontuações configuráveis.
