## Como as Varreduras Funcionam

O motor de Processamento e a **camada de execucao** do Data Quality Sense. Ele le as definicoes de varredura criadas no Builder, consulta dados em tempo real do Salesforce e produz pontuacoes de qualidade visiveis no Insight Studio.

![Dialogo de confirmacao Run Scan com tempo estimado e botao Run Scan](../../../../assets/screenshots/running-scans2.png)

## Acionando uma Varredura

As varreduras podem ser acionadas de tres formas:

1. **Manual** — Clique em "Run Scan" no Insight Studio
2. **Agendada** — Via [agendamento](/pt/processing/scheduling/) baseado em CRON
3. **Programatica** — Via API Apex (para integracoes personalizadas)
