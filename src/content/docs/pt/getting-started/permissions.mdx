## Atribuir um Permission Set Group

Atribua um grupo do pacote para cada função:

| Função | Grupo no Setup | Nome API | Permission Sets incluídos |
| --- | --- | --- | --- |
| Usuário | **DQS User Access** | `DQS_User_Group` | `dqs_user` |
| Administrador | **DQS Administrator Access** | `DQS_Admin_Group` | `dqs_user` + `dqs_admin` |

Em **Setup → Permission Set Groups**, abra o grupo, selecione **Manage Assignments → Add Assignments**, escolha os usuários e conclua a atribuição. O grupo administrador já inclui acesso básico; não é necessário atribuir ambos.

As atribuições diretas existentes continuam válidas e não são migradas automaticamente. Na atribuição direta, administradores precisam de `dqs_user` e `dqs_admin`; apenas `dqs_admin` não fornece a função completa.

## Recursos de cada função

**DQS User Access não é somente leitura.** Usuários podem criar e editar definições Draft, configurar capacidades e substituições por campo, importar campos de layouts, executar varreduras e consultar resultados. O Permission Set básico também concede criação, leitura, edição e exclusão nos objetos principais DQS de definições, resultados, agendamentos e logs de erros. As regras do aplicativo impõem restrições adicionais.

**DQS Administrator Access** acrescenta operações administrativas, incluindo exclusão de definições Draft e configuração, geração, histórico e exportação PDF de Field Usage. Nem administradores DQS podem excluir definições ativas.

## Acesso aos dados e ativação

Permissões de objetos e campos continuam valendo para os dados Salesforce analisados. O acesso DQS não garante acesso a todos os objetos de origem, campos ou metadados. Configurações Field Usage e relatórios salvos exigem acesso administrador e não fazem parte da função básica.

Atribuir um grupo não ativa o pacote. Conclua a [ativação do aplicativo](/pt/getting-started/installation/) separadamente após a instalação.
