## Data Quality Senseとは？

Data Quality Sense（DQS）は、CRMデータの品質を監視、測定、改善するための**Salesforceネイティブマネージドパッケージ**です。Salesforce組織内で完全に動作し、外部統合は不要で、データが環境外に出ることはありません。

標準のSalesforceプラットフォームには、大規模なデータ品質を測定するための組み込みツールがありません。DQSは、自動スキャン、構成可能な品質ディメンション、豊富な分析機能でこのギャップを埋めます。

## コアコンポーネント

### DQS Builder

スキャン構成を作成するためのマルチステップウィザード。オブジェクトの選択、フィールドの選択、品質ディメンションの選択、しきい値の設定をガイド付きUIで行えます。

### Insight Studio

スキャン結果のダッシュボードと分析。スコア、トレンド、フィールドヘルスマトリックス、スキャン比較、CSVエクスポート、AI搭載のレコメンデーション。

### 処理エンジン

柔軟なスケジューリング、データ保持ポリシー、エラー管理、プラットフォームイベント通知を備えた自動バッチスキャン。

## 品質ディメンション

DQSは**7つの品質ディメンション**でデータを評価します：

| ディメンション | 測定内容 |
|------------|---------|
| **Completeness** | フィールドは入力されていますか？ |
| **Validity** | 値は期待されるフォーマットに一致していますか？ |
| **Uniqueness** | 重複する値はありますか？ |
| **Timeliness** | データは最新ですか？ |
| **Consistency** | 関連フィールドは論理的に一貫していますか？ |
| **PII Detection** | 個人データは適切に処理されていますか？ |

各ディメンションはグローバルまたはフィールドごとに構成でき、しきい値とスコアリングを設定できます。
